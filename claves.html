Cómo usarla

Es una API compatible con OpenAI que reenvía a tu Ollama local. Dirección base:

Búsqueda web (agente): el servidor busca, junta el texto encontrado con la pregunta y se lo pasa al modelo. Actívala con "web_search": true en el cuerpo, o añadiendo +web al nombre del modelo. La clave debe tener el permiso «Web». Las fuentes salen en la cabecera X-Web-Sources y en el campo web_sources de la respuesta.

Modelo asignado: si la clave tiene un modelo asignado, "model" es opcional en las peticiones; pedir otro modelo devuelve un error 403.

Si el servidor responde «Falta la API key» aunque la envíes, comprueba que existe el archivo .htaccess junto a api.php y reinicia Apache. No expongas este servidor a internet: cualquiera con acceso a la página puede crear claves.
